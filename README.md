## 🛠️ Технологический стек

Проект написан на чистом коде (Vanilla), без использования тяжелых фреймворков, что обеспечивает моментальную загрузку.

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) **HTML5** - Семантическая верстка.
- ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) **CSS3** - Grid, Flexbox, Animations, Media Queries.
- ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black) **JavaScript (ES6+)** - Логика плеера, API, эффекты.
- **Twitch Embed API** - Встраивание плеера.
